# nvim config cheatsheet

Leader = `<Space>` (localleader тоже `<Space>` — они совпадают).

## Общее

| Клавиша | Режим | Действие |
|---|---|---|
| `\|` | n | Переключить тему по кругу (только внутри текущего light/dark режима, см. `lua/theme_toggle.lua`) |
| `<Esc>` | n | Снять подсветку поиска |
| `<Esc><Esc>` | terminal | Выйти из режима терминала |
| `<leader>=` | n | Вертикальный сплит |
| `<leader>-` | n | Горизонтальный сплит |
| `<leader>0` | n | Закрыть все окна, кроме текущего |
| `<C-h>` / `<C-j>` / `<C-k>` / `<C-l>` | n | Перейти в окно слева/снизу/сверху/справа |
| `<leader>q` | n | Список диагностик в quickfix |
| `<leader>tw` | n | Переключить перенос строк (`wrap`) |

Хоткеи работают независимо от раскладки macOS (кириллица/латиница) — `langmapper.nvim`
транслирует пользовательские маппинги на лету (сам `langmap` в `init.lua` этого не умеет,
подтверждённый баг Neovim). Вход в `:` командную строку сам переключает раскладку на US и
возвращает обратно при выходе (нужен `macism`, см. `init.lua`).

## Поиск (Telescope)

| Клавиша | Действие |
|---|---|
| `<leader>sf` | Поиск файлов |
| `<leader>sg` | Live grep по проекту |
| `<leader>sw` | Grep текущего слова под курсором |
| `<leader>s/` | Live grep только по открытым файлам |
| `<leader>/` | Fuzzy-поиск по текущему буферу |
| `<leader>sh` | Поиск по хелпу |
| `<leader>sk` | Поиск по своим keymaps |
| `<leader>sd` | Поиск по диагностикам |
| `<leader>sr` | Повторить последний поиск |
| `<leader>s.` | Недавние файлы |
| `<leader>sn` | Поиск по файлам конфига nvim |
| `<leader><leader>` | Список открытых буферов |
| `<leader>u` | История undo (telescope-undo) |

Поиск ускоряется `telescope-fzf-native.nvim` — это не консольный `fzf`, а нативный сортировщик именно для Telescope, работает незаметно.

## LSP (активны в буфере, когда подключён LSP-сервер)

| Клавиша | Действие |
|---|---|
| `gd` | Перейти к определению |
| `gD` | Перейти к декларации |
| `gr` | Найти все использования |
| `gI` | Перейти к реализации |
| `<leader>D` | Определение типа |
| `<leader>ds` | Символы в текущем файле |
| `<leader>ws` | Символы по всему проекту |
| `<leader>rn` | Переименовать (rename) |
| `<leader>ca` | Code action |

## Форматирование (conform.nvim, + автоформат при сохранении)

| Клавиша | Действие |
|---|---|
| `<leader>ff` | Отформатировать буфер вручную |

Форматтеры по языкам: Lua → `stylua`, Python → `isort`+`black`, JS/TS → `prettierd`/`prettier`, JSON/Markdown/CSS/SCSS → `prettier`/`prettierd`, HTML → `prettierd`, Bash → `beautysh`, YAML → `yamlfix`, Dart → `dart_format` (не установлен, пункт неактуален, если не пишете на Dart).

### Git-хунки (gitsigns.nvim)

| Клавиша | Режим | Действие |
|---|---|---|
| `]c` / `[c` | n | Прыжок к следующему/предыдущему изменению |
| `<leader>hs` | n, v | Застейджить хунк |
| `<leader>hr` | n, v | Откатить хунк |
| `<leader>hS` | n | Застейджить весь буфер |
| `<leader>hR` | n | Откатить весь буфер |
| `<leader>hp` | n | Превью хунка |
| `<leader>hb` | n | Blame текущей строки |
| `<leader>hd` | n | Diff буфера против индекса |
| `<leader>hD` | n | Diff буфера против последнего коммита |
| `<leader>tb` | n | Toggle blame по текущей строке (виртуальный текст) |
| `<leader>tD` | n | Toggle показа удалённых строк |

`vim-fugitive` остаётся для командного git-порцелейна (`:G`, `:Git blame`...), `lazygit`
(`<leader>tl`, см. ниже) — для полноценного TUI со стейджингом/коммитами/ветками. Три инструмента
не дублируют друг друга: gitsigns — точечные правки прямо в буфере, fugitive — команды, lazygit —
обзор репозитория целиком.

## Плавающий терминал (vim-floaterm) — внешние TUI-тулзы

| Клавиша | Что открывает | Что это |
|---|---|---|
| `<leader>1` | Toggle обычного терминала | Просто шелл в плавающем окне |
| `<leader>tl` | `lazygit` | Git TUI: стейджинг, коммиты, ветки, история — своими хоткеями |
| `<leader>td` | `lazydocker` | Docker TUI: контейнеры, образы, логи — своими хоткеями |
| `<leader>ty` | `ytop` | Монитор ресурсов системы (CPU/RAM/сеть) — своими хоткеями |
| `<leader>tf` | `fzf` | Консольный фаззи-поиск как отдельный процесс в терминале (не путать с telescope-fzf-native выше) |

Внутри этих окон работают **родные** хоткеи каждой утилиты, nvim их не переопределяет. Закрыть: `<leader>1` ещё раз или `<Esc><Esc>` + `:q`.

## Не на macOS (Linux/сервер)

Конфиг один на все машины, но пара мест зависит от окружения:

- **Буфер обмена.** На маке работает `pbcopy`. Там, где нативного инструмента нет (headless
  Linux по SSH), `init.lua` сам подменяет провайдера на **OSC 52** — копирование уходит
  терминалу (ghostty/kitty/wezterm умеют), то есть в буфер *локальной* машины. Если терминал
  не отвечает на чтение (paste), nvim подождёт секунду и предупредит — вставлять лучше
  терминалом (Cmd+V).
- **Парсеры treesitter** ставятся командой `require("nvim-treesitter").install{...}` при старте;
  для сборки нужен `tree-sitter` CLI (`tree-sitter-cli` в Arch), иначе будет
  `ENOENT: 'tree-sitter'`. Один раз, потом лежат в `~/.local/share/nvim`.
- **LSP и stylua** ставятся через Mason при первом запуске (`pyright`, `ts_ls`, `lua_ls`,
  `stylua`) — нужны `node`/`npm` и сеть.
- **Форматтеры** (conform) берутся из системы: `stylua` (Mason), `black`+`isort`, `prettier`.
  Без `beautysh`/`yamlfix` автоформат просто не сработает для bash/YAML, ошибок не будет.
- `macism` (переключение раскладки в `:`-командной строке) — только мак, на Linux блок
  пропускается.
